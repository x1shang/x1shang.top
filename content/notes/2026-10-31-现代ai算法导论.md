# 第一讲 AI 的背景和经典技术

- 什么才算是人工智能？
    - 不是越像人越好，因为人会犯错误
    - AI 是设计能够针对目标**合理行动**的计算机算法。一个例子：导航。
	- 智能体感知环境，根据获得的信息采取行动，行动又会改变环境。
	- 要素：状态，动作，转移，代价，目标
	- 举例：CSP（类似数独的约束问题），概率推理，机器学习

本节常见符号：

| 符号                          | 解释                               |
| --------------------------- | -------------------------------- |
| $x_i,y_i,\hat y_i$          | 第 $i$ 条样本的输入、正确答案、模型预测           |
| $n,d$                       | 样本数量、每条样本有多少个输入特征                |
| $\theta$                    | 可训练参数矩阵(向量)；可以包含权重 $w,W$ 和偏置 $b$ |

| $\arg\min_\theta J(\theta)$ | 找出让 $J$ 最小的参数；结果是参数，不是最小损失值      |
| $\mathbb E$                 | 按发生概率加权的平均                       |
| $\eta$                      | 学习率，控制每次更新幅度                     |
| $\leftarrow$                | 程序赋值                             |

## 1.0 损失、泛化
**Loss&Generalization**

$$
\text{损失：}J(\theta)=\frac1n\sum_{i=1}^n\ell\bigl(y_i,f_\theta(x_i)\bigr).
$$
$\ell$ 就是损失函数，常见以下几种：

| 损失   | 公式                       | 解释                                |
| ---- | ------------------------ | --------------------------------- |
| 平方损失 | $(\hat y-y)^2$           | 大错误罚得特别重。和除以n就得到MSE均方误差。          |
| 绝对损失 | $\lvert  \hat y-y\rvert$ | 错多少罚多少，不让正负错误抵消                   |
| 零一损失 | $\mathbf1[\hat y\ne y]$  | 分类错了记 1，对了记 0；不表示“差一点”和“差很多”      |
| 对数损失 | $-\log p_y$              | $p_y$ 是模型给正确类别的概率；给正确答案的概率越小，惩罚越大 |

$$
\text{泛化：}R(\theta)=\mathbb E_{(X,Y)\sim P}\bigl[\ell(Y,f_\theta(X))\bigr].
$$
显然泛化指模型在没见过的新数据上，**仍然能做好任务的能力**。

可能出现的问题：

- **欠拟合**：规则太简单，或训练不足，练习题和新题都做不好。
- **过拟合**：学到了训练数据的偶然细节，练习题表现很好，新题明显变差。模型更复杂会增加这种可能性，但并非必然过拟合。

因此，我们通常把已有数据分开使用：

- **训练集**：用于调整模型参数。
- **验证集**：用于比较模型、调整训练方式或结构。
- **测试集**：在模型确定后，用于评估它面对未参与训练和选择的数据时的表现。

**评估我们的模型：**

| 指标      | 公式                                            | 解释                                    |
| ------- | --------------------------------------------- | ------------------------------------- |
| MAE     | $\frac1n\sum_i\lvert e_i\rvert$               | 平均错多少，单位与答案相同                         |
| MSE     | $\frac1n\sum_i e_i^2$                         | 平均平方误差，更强调大错误                         |
| RMSE    | $\sqrt{\mathrm{MSE}}$                         | 把平方单位还原，仍然强调大错误                       |
| 平均有符号误差 | $\frac1n\sum_i e_i$                           | 看整体偏高还是偏低；正负抵消，所以不是总体准确度              |
| MAPE    | $\frac{100\%}{n}\sum_i\lvert e_i/y_i\rvert$   | 平均相对误差；$y_i=0$ 时该式不可用，接近 0 也很敏感       |
| $R^2$   | $1-\frac{\sum_i e_i^2}{\sum_i(y_i-\bar y)^2}$ | 和“总猜本组答案的均值”相比改善多少；可小于 0，分母为 0 时此式无定义 |

## 2.1 K-means

$$
\phi(\{x_i\},\{a_i\},\{c_k\}) = \sum_i \operatorname{dist}(x_i,c_{a_i})
$$

它的意思是：**把每个数据点到它所属类别中心的距离加起来，K-means 尝试让这个总和尽可能小。**

### 公式里的符号

假设我们有一堆数据点，想把它们分成 $K$ 类：

- $x_i$：第 $i$个数据点。例如，一个人的身高和体重可以组成一个二维点。
- $c_k$：第$k$ 类的中心，也叫**聚类中心**或均值。
- $a_i$：第$i$ 个点被分到的类别编号，取值为 $1,\ldots,K$。
- $c_{a_i}$：第 $i$ 个点所属类别的中心。比如 $a_i=2$，那么它对应的中心就是 $c_2$。
- $\operatorname{dist}(x_i,c_{a_i})$：点 $x_i$ 与其所属中心之间的距离。
- $\sum_i$：把所有数据点对应的距离加起来。
- $\phi$：衡量当前聚类结果的一个数，越小说明各点总体上越靠近各自的中心。

$\operatorname{dist}$ 表示距离，标准 K-means 通常采用**欧氏距离的平方**：

$$
\boxed{ \min_{\{a_i\},\{c_k\}} \phi = \min_{\{a_i\},\{c_k\}} \sum_{i=1}^{n} \left\|x_i-c_{a_i}\right\|_2^2 }
$$

其中 $n$ 是数据点的数量，$\min$ 表示寻找使目标值尽可能小的分类方式和中心位置。

如果 $x_i=(x_{i1},x_{i2})$，中心 $c_{a_i}=(c_1,c_2)$，那么平方欧氏距离是：

$$
\left\|x_i-c_{a_i}\right\|_2^2 = (x_{i1}-c_1)^2+(x_{i2}-c_2)^2
$$

例如点 $(2,3)$ 到中心 $(1,1)$ 的平方距离是：

$$
(2-1)^2+(3-1)^2=5
$$

### 这个公式怎么用？

通过反复交替执行两步，来降低上面的目标值：

**第一步：固定中心，重新分组。**

每个点被分给离它最近的中心：

$$
a_i=\underset{k\in\{1,\ldots,K\}}{\arg\min} \left\|x_i-c_k\right\|_2^2
$$

这里的 $\arg\min$ 表示“使距离最小的那个 $k$”。例如，一个点离第 2 个中心最近，就令 $a_i=2$。

**第二步：固定分组，重新计算中心。**

对每个类别，把分到这一类的所有点取平均：

$$
c_k= \frac{1}{|C_k|} \sum_{i\in C_k}x_i, \qquad C_k=\{i:a_i=k\}
$$

然后重复“**分给最近的中心 → 重新计算平均值**”，直到点的类别不再变化。
这两步各自都不会让平方距离总和变大：第一步让每个点选择最近的中心，第二步让每类的中心移动到该类点的平均位置。不过，最终结果**不一定是全局最优**；初始中心选得不同，结果也可能不同。

```python
import random
def kmeans(points, k, max_iter=300, random_state=None):
    """
    points: 点的列表，例如 [[1, 1], [2, 3], [8, 9]]
    k: 想分成的组数
    返回 k 个中心，每个中心是一个坐标列表。
    """
    if not points or not 1 <= k <= len(points):
        raise ValueError("points 不能为空，且 k 必须在 1 和点数之间")

    dimension = len(points[0])
    if dimension == 0 or any(len(point) != dimension for point in points):
        raise ValueError("所有点必须有相同且非零的维度")
    if max_iter < 1:
        raise ValueError("max_iter 必须至少为 1")

    rng = random.Random(random_state)

    # 随机选择 k 个点作为初始中心
    centers = [list(point) for point in rng.sample(points, k)]
    previous_labels = None

    for _ in range(max_iter):
        labels = []

        # 1. 对每个点，找距离它最近的中心
        for point in points:
            distances = [
                sum((point[d] - center[d]) ** 2 for d in range(dimension))
                for center in centers
            ]
            closest_center = min(range(k), key=lambda j: distances[j])
            labels.append(closest_center)

        # 分组不变，停止
        if labels == previous_labels:
            break

        # 2. 每个中心更新为对应组中所有点的平均值
        for j in range(k):
            group = [
                point for point, label in zip(points, labels)
                if label == j
            ]

            if group:
                centers[j] = [
                    sum(point[d] for point in group) / len(group)
                    for d in range(dimension)
                ]

        previous_labels = labels

    return centers
```

## 2.2 线性回归与最小二乘法
**Regression**

模型学习到一个拟合函数，设计奖惩函数，根据近似程度做出反馈。
假设模型得到函数：

$$
\hat y=\theta_1x+\theta_2
$$

假设我们有 $n$ 组历史数据：

$$
(x_1,y_1),(x_2,y_2),\ldots,(x_n,y_n)
$$

对于第 $i$ 组数据，预测误差是：

$$
\hat y_i-y_i
$$

损失：

$$
L(\theta_1,\theta_2) = \sum_{i=1}^{n} (\theta_1x_i+\theta_2-y_i)^2
$$

使得损失最小的过程就是*最小二乘法*：

$$
\boxed{ \min_{\theta} L(\theta) = \min_{\theta} \sum_{i=1}^{n}(f_i^{T}\theta-y_i)^2 }
$$

求最小二乘解：
对原函数求导：$\nabla L(\theta)=0$
矩阵可逆的情况下：一种闭式解

$$
\boxed{\theta=(X^TX)^{-1}X^Ty}
$$

## 2.3 分类与线性分类器
**Classification&LinearClassifiers**

训练数据可以写成$(f_1,y_1),(f_2,y_2),\ldots,(f_n,y_n)$
这里：

- $f_i$ 是第 $i$ 个样本的**特征**，即用来判断的信息。例如邮件的特征可以包括有没有某些词、链接数量等。
- $y_i$ 是这个样本的**标签**，例如“垃圾邮件”或“正常邮件”。
- $n$ 是训练样本的数量。

学习算法利用这些带标签的数据，得到一个分类模型。将来遇到一封**没有见过的新邮件**时，模型根据它的特征预测标签。

对于最简单的二分类情况（正常邮件/垃圾邮件），标签显然可以简记为$\{-1,1\}$,此时使用**线性分类器** （$\theta$是权重向量，f是输入的特征向量）

$$
h(f)=\theta^Tf+\underset{\text{偏置}}{b}
$$

$h(f)$的正负就代表了数据点的类别。
同样的，任务就是通过机器学习找到最佳的$\theta$和$b$

## 2.4 神经网络
**NeuralNetwork**

可是我们会遇到线性分类器无法处理的情况
![线性可分与线性不可分的示例](assets/notes/modern-ai-introduction/linear-separability.webp)

对于后两个图的情况，我们就需要应用非线性变换去解决。神经网络通过多层计算和非线性激活函数，适合学习非线性的复杂模型。

仍然以这个分类举例，一个神经元可以是：

$$
\begin{aligned}
\text{output}=&\underset{\text{激活函数}}{g}\left(\underset{\text{预激活值}}{h(f)}\right)\\
\text{其中，预激活值可以表达为 }z=&h(f)=Wx+b
\end{aligned}
$$

- g是激活函数，例如正负值做区分。但是它更经常用来引入非线性，例如它还有以下这些种类
![常见激活函数及其图像](assets/notes/modern-ai-introduction/activation-functions.webp)
- 进一步，神经网络由输入层、隐藏层、输出层组成。

### 卷积神经网(CNN)
**ConvolutionalNeuralNetwork**

- 局部连接(滤波器)+参数共享
- 2012年，FeiFei Li创办的ILSVRC大赛中AlexNet凭借着一张极其精巧的CNN使得图片识别模型能力得到大幅提升。
### 循环神经网(RNN)
**RecurrentNeuralNetwork**

- 拥有“缓存”，关注顺序，传递状态
- RNN 必须一步步往前算，长距离信息容易衰减、也没法并行；LLM所用的***Transformer*** 网络用自注意力让任意两个位置直接相连，代价是计算量随长度平方增长。

例如句子“我昨天去图书馆借了一本书。”被RNN视为一个序列，要理解后面的“书”，前面的“图书馆”“借”都可能有帮助。处理时间序列时也是一样：预测下一个时刻，可能需要参考之前发生过什么。

RNN 的思路是：每处理一个新输入，同时参考前一步留下的**隐藏状态**。

一个简化公式是：

$$
\boxed{h_t=g(W_xx_t+W_hh_{t-1}+b)}
$$

其中：

- $x_t$：第 $t$ 步的新输入，例如当前的词。
- $h_{t-1}$：上一步的隐藏状态，携带之前序列的信息。
- $h_t$：结合当前输入和之前状态后得到的新状态。
- $W_x,W_h,b$：需要训练的参数。

# 第三讲 优化与反向传播
**Optimization & Backpropagation**

- 构建神经网络如何优化参数、训练模型？
	- 最小化损失
		- 最小化的过程：**梯度下降** & SGD
		- 衡量损失在各参数的比重：**反向传播**

## 3.5 梯度下降
**Gradient Descent**

$$
\boxed{\theta_{t+1}=\theta_t-\eta\nabla_\theta J(\theta_t)}
$$

**学习率$\eta$的作用：** 太小可能下降得很慢；太大可能跨过低点，在两侧反复震荡，甚至越走越远。负梯度反映的是**当前位置附近**的下降方向，不能保证走很大一步后损失仍然减小。

## 3.6 随机梯度下降与小批量
**Stochastic Gradient Descent, SGD**

def convex:

$$
J(\lambda u+(1-\lambda)v)\leq\lambda J(u)+(1-\lambda)J(v),\qquad 0\leq\lambda\leq1
$$

在适当的光滑性和学习率等条件下，梯度下降对凸优化问题有收敛保证；具体保证和收敛速度还依赖这些条件，并不是任意凸函数、任意学习率都可以。

神经网络的损失函数通常是**非凸的**，可能有多个局部低点或其他使优化变慢的位置。梯度下降及其变体在实际中仍然常常有效，但一般不能保证找到全局最优解。

如果训练集非常大，每更新一次都用全部样本计算梯度，计算成本会很高。SGD 的思路是：每次随机取一条或一小批样本，用这部分数据计算梯度，作为整体梯度的近似。

设当前选中的小批量为 $B$，包含 $|B|$ 条样本：

$$
g_B=\frac{1}{|B|}\sum_{i\in B}\nabla_\theta\ell\bigl(y_i,f_\theta(x_i)\bigr),
\qquad
\boxed{\theta\leftarrow\theta-\eta g_B}
$$

这里 $g_B$ 是**当前批次的平均梯度**；$\ell$ 是单条样本的损失。每次换一批数据，再计算并更新。

| 方法      | 每次更新使用的数据 | 特点                 |
| ------- | --------- | ------------------ |
| 批量梯度下降  | 全部训练样本    | 每步使用完整梯度，数据多时计算成本高 |
| 单样本 SGD | 一条样本      | 每步计算较少，但更新方向波动较大   |
| 小批量 SGD | 一小批样本     | 在计算效率和梯度波动之间折中     |

小批量梯度只是近似，因此**某一次更新不一定让整个训练集的损失下降**；通常要看较长时间的变化趋势。

一轮 **epoch** 指遍历一次训练集；一次 **step** 指更新一次参数。例如 1000 条样本、每批 100 条，则一轮有 10 次参数更新。

```text
初始化参数 theta
重复若干轮：
    打乱训练样本
    对每个小批量 B：
        计算 B 上的平均损失及其梯度 g_B
        theta = theta - 学习率 * g_B
```

## 3.7 反向传播与梯度流
**Backpropagation & Gradient Flow**

训练模型需要计算损失，计算损失需要知道所有参数的比重，反向传播就是计算比重的过程，本质上就是求解梯度。在真实计算中，往往使用链式法则**分拆**与**合并**以简便计算过程。
$$
\frac{\partial f}{\partial x}
=\underbrace{\frac{\partial f}{\partial q}}_{\text{上游梯度}}
\times
\underbrace{\frac{\partial q}{\partial x}}_{\text{局部梯度}}
$$

- **局部梯度**：当前这个小运算的输出对输入的变化率。
- **上游梯度**：最终结果对当前运算输出的变化率，从后面的计算传回来。
- 如果一个变量通过**多条路径**影响最终结果，需要把各条路径的梯度贡献**相加**。

### 常见节点的反向传播规则

设 $g$ 是传到当前节点输出的上游梯度：

| 名称        | 前向计算                     | 反向传播                    | 理解              |
| --------- | ------------------------ | ----------------------- | --------------- |
| *add gate*  | $q=a+b$                  | $a$、$b$ 各收到 $g$         | 任一输入增加 1，和就增加 1 |
| *mul gate*  | $q=ab$                   | $a$ 收到 $gb$；$b$ 收到 $ga$ | 对一个数求导时，乘上另一个数  |
| *copy gate* | 同一个值进入多条分支               | 各分支传回的梯度相加              | 每条路径都可能影响结果     |
| *max gate*  | $q=\max(a,b)$，且 $a\ne b$ | 较大者收到 $g$，较小者收到 0       | 局部变化时，输出由较大者决定  |

最大值相等时可能不可微，此时需要特别约定；
上面的例子算的是 $f$ 对 $x,y,z$ 的梯度。实际训练需要的是**损失 $J$ 对参数的梯度**，因此还要把损失函数作为计算图的最后一部分。：
$$
\text{例如 }J=(f-y_{\text{target}})^2,\qquad
\frac{\partial J}{\partial w}
=2(f-y_{\text{target}})\frac{\partial f}{\partial w}
$$
$w$ 是模型中的某个参数。前一部分体现预测误差，后一部分体现参数对预测的影响，两者相乘得到参数对损失的影响。

### 训练过程

每一次小批量训练，可以按下面的顺序理解：

1. **前向传播**：输入数据，用当前参数算出预测，并保存需要的中间结果。
2. **计算损失**：比较预测和答案，得到当前批次的损失。
3. **反向传播**：从损失出发，沿计算图倒着使用链式法则，求出各参数的梯度。
4. **更新参数(gradient descent)**：优化器使用梯度和学习率，调整参数。
5. 换一批数据，重复以上过程。

```text
for 每个小批量 (x, y):
    清除上一次更新留下的梯度
    prediction = 模型前向计算(x)
    loss = 计算损失(prediction, y)
    对 loss 执行反向传播，得到各参数的梯度
    参数 = 参数 - 学习率 * 梯度
```

```python
import numpy as np
from numpy.random import randn

# define the network
N, D_in, H, D_out = 64, 1000, 100, 10
x, y = randn(N, D_in), randn(N, D_out)
w1, w2 = randn(D_in, H), randn(H, D_out)

for t in range(2000):
    # forward pass
    h = 1 / (1 + np.exp(-x.dot(w1)))
    y_pred = h.dot(w2)
    loss = np.square(y_pred - y).sum() # loss calculation
    print(t, loss)

    # backpropagation
    grad_y_pred = 2.0 * (y_pred - y)
    grad_w2 = h.T.dot(grad_y_pred)
    grad_h = grad_y_pred.dot(w2.T)
    grad_w1 = x.T.dot(grad_h * h * (1 - h))

    # gradient descent
    w1 -= 1e-4 * grad_w1
    w2 -= 1e-4 * grad_w2
```

**Markov Decision Process (MDP)**

本讲用已知的转移概率和奖励求最优策略。下一讲讨论如何从交互样本中学习。

**常见符号**

| 符号 | 含义 |
| --- | --- |
| $s\in S,\ a\in A$ | 状态与动作 |
| $P(s'\mid s,a)$ | 转移概率，也记作 $T(s,a,s')$ |
| $R(s,a,s')$ | 转移的即时奖励，有时简写为 $R(s,a)$ 或 $R(s')$ |
| $\gamma$ | 折扣因子 |
| $\pi,\ \pi^*$ | 策略、最优策略 |

## 4.8 MDP 的基本模型与策略

### MDP 的定义与马尔可夫性

**示例：网格世界（Grid World）**

> 在 $3\times4$ 的网格里，第 2 行第 2 列是墙，右上和右侧中间分别是 $+1$ 和 $-1$ 出口。选择向上时，实际尝试向上、向左、向右移动的概率分别为 $0.8$、$0.1$、$0.1$。撞墙或越界则留在原格。普通移动获得每步奖励（living reward），执行退出动作时获得出口奖励。（课件第 8–9 页）
>
> 固定动作噪声为 $0.2$，改变每步奖励会改变最优策略。（课件第 15 页）
>
> | 每步奖励 | 策略特点 |
> | --- | --- |
> | $0$ | 借边界或绕路避开 $-1$ |
> | $-0.03$ | 沿较安全的路线前往 $+1$ |
> | $-0.4$ | 底行走离 $-1$ 更近的捷径前往 $+1$ |
> | $-2.0$ | 中下区域可选 $-1$ 尽快结束，顶行仍走向 $+1$ |

**示例：赛车（Racing）**

> 赛车根据当前的温度状态选择慢开（Slow）或快开（Fast）。过热时回合结束。（课件第 16–17 页）
>
> | 状态 | 动作 | 下一状态（概率，即时奖励） |
> | --- | --- | --- |
> | Cool | Slow | Cool（$1.0,\,+1$） |
> | Cool | Fast | Cool（$0.5,\,+2$）或 Warm（$0.5,\,+2$） |
> | Warm | Slow | Cool（$0.5,\,+1$）或 Warm（$0.5,\,+1$） |
> | Warm | Fast | Overheated（$1.0,\,-10$） |

**共同结构**。两个例子都可以用 MDP 建模，由状态集合 $S$、动作集合 $A$、转移概率 $P$、奖励函数 $R$ 和起始状态 $s_0$ 组成，也可以设终止状态。

- **状态与动作**。智能体观察当前状态 $s$（所在格子或赛车温度），从该状态可用的动作中选一个 $a$。
- **概率转移**。动作选定后，环境按 $P(s'\mid s,a)$ 决定下一状态。选择向上仍可能侧滑，冷车快开也可能升温。所有可能的下一状态的概率之和为 $1$。若某个结果的概率为 $1$，这一步就是确定的。
- **即时奖励**。一次转移 $(s,a,s')$ 带来奖励 $R(s,a,s')$，例如退出网格获得 $+1$，赛车过热得到 $-10$。各步奖励按折扣累加成回报。

一步交互记为 $(s_t,a_t,r_{t+1},s_{t+1})$，其中 $r_{t+1}=R(s_t,a_t,s_{t+1})$。

**马尔可夫性**。给定当前状态和动作后，更早的历史不影响下一状态的概率分布。

$$
P(S_{t+1}=s'\mid S_0,A_0,\ldots,S_t,A_t)
=P(S_{t+1}=s'\mid S_t,A_t)
$$

### 策略（Policy）

确定性策略 $\pi:S\to A$ 为每个可行动的状态指定动作。最优策略 $\pi^*$ 最大化期望折扣回报。

### 搜索树视角与折扣回报

搜索树中，$s$ 是状态节点，$(s,a)$ 是选定动作后的节点（q-state），$(s,a,s')$ 是标有转移概率和即时奖励的分支。

从时刻 $t$ 开始的**折扣回报**为

$$
G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k+1}.
$$

无限视野下，若 $0\le\gamma<1$ 且每步奖励满足 $\lvert r_t\rvert\le R_{\max}$，则 $\lvert G_t\rvert\le R_{\max}/(1-\gamma)$。

## 4.9 价值函数与 Bellman 方程

$V(s)$ 和 $Q(s,a)$ 分别表示状态价值和状态–动作价值。下表中每个值都是**期望折扣回报**。

| 符号 | 第一步 | 后续动作 |
| --- | --- | --- |
| $V^\pi(s)$ | 按 $\pi$ 选择 | 按 $\pi$ 选择 |
| $Q^\pi(s,a)$ | 指定为 $a$ | 按 $\pi$ 选择 |
| $V^*(s)$ | 最优选择 | 最优选择 |
| $Q^*(s,a)$ | 指定为 $a$ | 最优选择 |

因此 $V^\pi(s)=Q^\pi(s,\pi(s))$。最优价值满足 **Bellman 最优性方程**。

$$
\begin{aligned}
Q^*(s,a)&=\sum_{s'}P(s'\mid s,a)\bigl[R(s,a,s')+\gamma V^*(s')\bigr],\\
V^*(s)&=\max_a Q^*(s,a)\\
      &=\max_a\sum_{s'}P(s'\mid s,a)\bigl[R(s,a,s')+\gamma V^*(s')\bigr].
\end{aligned}
$$

## 4.10 值迭代

从 $V_0(s)=0$ 开始，用上一轮的值同步更新各非终止状态，直到变化量小于设定阈值。终止状态的值为 $0$。

$$
V_{k+1}(s)\leftarrow
\max_a\sum_{s'}P(s'\mid s,a)\bigl[R(s,a,s')+\gamma V_k(s')\bigr]
$$

有限 MDP 中，每轮复杂度为 $O(\lvert S\rvert^2\lvert A\rvert)$。当 $\gamma<1$ 时，$V_k$ 收敛到唯一的 $V^*$。

**网格世界的值迭代**。第 $k$ 轮格子里的数字是 $V_k(s)$，即只考虑接下来 $k$ 步的最优状态价值。箭头是根据当前估计选出的动作。比较 $k=12$ 和 $k=100$ 两轮，箭头相同，部分格子的数值仍有变化。（课件第 28–41 页）

## 4.11 策略评估、策略抽取与策略迭代

### 策略评估（Policy Evaluation）

给定策略 $\pi$，求它的状态价值 $V^\pi$。

$$
V^\pi(s)=\sum_{s'}P(s'\mid s,\pi(s))\bigl[R(s,\pi(s),s')+\gamma V^\pi(s')\bigr]
$$

可用上式迭代更新，每轮 $O(\lvert S\rvert^2)$，也可直接解线性方程组 $(I-\gamma P_\pi)V^\pi=b_\pi$，其中 $P_\pi$ 是按策略行动时的转移矩阵，$b_\pi$ 是各状态的期望即时奖励。

**走廊例子**。上方出口为 $+100$，两侧出口为 $-10$。噪声为 $0.2$，$\gamma=0.9$，每步奖励为 $0$。（课件第 51–52 页）

| 固定策略 | 上格 | 中格 | 下格 |
| --- | --- | --- | --- |
| 一直向右 | $1.09$ | $-7.88$ | $-8.69$ |
| 一直向上 | $70.20$ | $48.74$ | $33.30$ |

### 策略抽取（Policy Extraction）

已知 $V^*$ 时，用模型做**一步前瞻**。已有 $Q^*$ 时，可直接比较动作的价值。

$$
\pi^*(s)\in\arg\max_a Q^*(s,a)
=\arg\max_a\sum_{s'}P(s'\mid s,a)\bigl[R(s,a,s')+\gamma V^*(s')\bigr]
$$

### 策略迭代（Policy Iteration, PI）

先评估当前策略 $\pi_i$ 得到 $V^{\pi_i}$，再做一步前瞻改进策略。

$$
\pi_{i+1}(s)\in\arg\max_a\sum_{s'}P(s'\mid s,a)
\bigl[R(s,a,s')+\gamma V^{\pi_i}(s')\bigr]
$$

并列时优先保留原动作。若改进后策略不变，$V^{\pi_i}$ 就满足 Bellman 最优性方程，因此 $\pi_i$ 已最优。走廊例子中，从“一直向右”出发，改进一次便得到“一直向上”。（课件第 60–61 页）

| 算法 | 每轮操作 | 开销 |
| --- | --- | --- |
| 值迭代（VI） | 更新一次状态价值 | 每轮 $O(\lvert S\rvert^2\lvert A\rvert)$，通常需要更多轮 |
| 策略迭代（PI） | 完整评估策略，再改进一次 | 每轮需解方程或迭代评估至收敛，通常需要较少轮 |

**赛车例子的 Python 实现**。用值迭代求 $V^*$ 的近似值，再用一步前瞻抽取策略。

```python
# mdp[state][action] = [(prob, next_state, reward), ...]
racing_mdp = {
    "Cool": {
        "Slow": [(1.0, "Cool", 1)],
        "Fast": [(0.5, "Cool", 2), (0.5, "Warm", 2)],
    },
    "Warm": {
        "Slow": [(0.5, "Cool", 1), (0.5, "Warm", 1)],
        "Fast": [(1.0, "Overheated", -10)],
    },
    "Overheated": {},
}


def value_iteration(mdp, gamma=0.9, eps=1e-6):
    """对有限 MDP 执行值迭代，并抽取最优策略。"""
    V = {s: 0.0 for s in mdp}

    while True:
        V_new = {}
        delta = 0.0
        for s, actions in mdp.items():
            if not actions:
                V_new[s] = 0.0
                continue
            V_new[s] = max(
                sum(p * (r + gamma * V[s_next]) for p, s_next, r in transitions)
                for transitions in actions.values()
            )
            delta = max(delta, abs(V_new[s] - V[s]))
        V = V_new
        if delta < eps:
            break

    # policy extraction (one-step lookahead)
    pi = {}
    for s, actions in mdp.items():
        if actions:
            pi[s] = max(
                actions,
                key=lambda a: sum(
                    p * (r + gamma * V[s_next]) for p, s_next, r in actions[a]
                ),
            )
    return V, pi


V_star, pi_star = value_iteration(racing_mdp, gamma=0.9)
# V_star ≈ {'Cool': 15.5, 'Warm': 14.5, 'Overheated': 0.0}
# pi_star = {'Cool': 'Fast', 'Warm': 'Slow'}
```
